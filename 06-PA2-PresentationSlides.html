User context

Mobile context turns small issues into real friction

63.9%

Read sports/chess news using smartphones

44.4%

Usually hold the phone with one hand

41.7%

Change grip depending on context

52.8%

Had never heard of Freestyle Chess

We prioritize issues that happen in short sessions, on small screens, and when users do not want to retry repeatedly.

03 / 20
Key findings

Three insights directly shape the proposal

Fast access first

Users want quick access to results, latest news, ratings, and player information within 2–3 minutes.

The menu is visible, but hard to reach

Findability is acceptable, but 43.1% had to stretch, change grip, or use the other hand.

Long lists need support

61.1% struggled when they could not recall the exact player, event, or information name.

Navigation and information retrieval are the clearest mobile bottlenecks.

04 / 20
Affinity board

From scattered observations to four problem clusters

A · Ergonomic NavigationThe top-left hamburger forces one-handed users to change grip.
B · Homepage OnboardingNew users need to understand Freestyle Chess faster.
C · Search & RetrievalLong Rating, News, and Schedule information need clearer retrieval support — search, filters, or richer previews.
D · Video FeedbackLoading and multiple playback are frustrating, but lean more toward bug fixes.
05 / 20
Prioritization

Choose fewer problems, but make them worth solving

Problem Short description Decision Score
P-01 One-handed reachability issue with top-left hamburger menu Selected 19/20
P-02 Lack of sticky search & filtering on long Rating / News lists Selected 18/20
P-03 Overlapping video audio & missing loading feedback Not proposal focus 18/20
P-04 Overloaded hero & onboarding gap Lower priority 16/20
P-05 Schedule lacks match/tournament detail for dedicated followers Carried forward (qualitative) 10/20

P-01 and P-02 are interaction-model problems; P-03 is closer to an implementation fix. P-05 has narrow evidence — P09 only, no survey backing — but P09 behaves like a retention-critical chess follower, so we kept it as a qualitative addition.
